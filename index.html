我的名字是 Tomasz Szmajda（ITom），我是一名专注于交互式 Web 体验的前端开发者。 我在软件工程领域的旅程始于对逻辑与美学如何交织融合的着迷。多年来，我不断打磨自己的技能，不仅是在构建功能性的网站，更是在打造能给用户留下深刻印象的产品。 我相信，2026 年及以后的 Web 需要的不仅仅是响应式设计；它需要动效、深度与交互性。

核心技术技能与栈

作为一名现代 Web 开发者，一个稳健而多元的技术栈至关重要。我的技术栈经过精心挑选，旨在实现高性能、可扩展性与可维护性。

  • 核心基础：进阶 JavaScript（ES6+）、TypeScript、HTML5、语义化标记，以及现代 CSS 架构，包括 SCSS、CSS Modules 与 Tailwind CSS。
  • 框架与生态：深入掌握 React.js 与 Next.js，用于构建极速、对 SEO 友好的 Web 应用。我借助 React 生态进行状态管理、路由处理与复杂 UI 逻辑的实现。
  • 3D 图形与 WebGL：我的招牌技能在于使用 Three.js 与 React Three Fiber（R3F） 进行 3D 可视化。我创建自定义着色器、优化复杂几何体，并管理重量级 3D 资源，以确保浏览器中 60fps 的稳定性能。
  • 动画：精通 GSAP（GreenSock 动画平台）与 Framer Motion，编排精密的、基于物理的 UI 动画与滚动联动的体验。
  • 后端与云：具备使用 Node.js、Express、Firebase 与 Supabase 集成后端服务的经验。我主要部署在 Vercel 与 Cloudflare Pages 等平台上。
  • 设计工具：熟练使用 Figma、Adobe Photoshop 与 Blender（用于 3D 资源准备），在设计与代码之间架起桥梁。

作品集：精选作品与案例研究

在 3D 作品集房间里，你可以漫步于一场展览，欣赏我最重要的商业项目与个人项目。以下是 Tomasz Szmajda 所创作作品的详细介绍。

MoneTune - 全栈金融仪表盘

MoneTune 是一款体量庞大的全栈 Web 应用，诞生于更好地追踪与管理个人财务的需求。 它采用现代 React 前端与安全、可扩展的后端架构构建，帮助用户可视化消费习惯、追踪周期性订阅，并设定动态的预算目标。 其 UI 包含复杂的数据可视化图表、实时更新，以及一个直观的仪表盘，让财务规划变得完全无摩擦。 开发 MoneTune 促使我构建稳健的关系型数据库、安全地处理敏感的用户认证，并为前端即时渲染优化海量数据集。

TimberKitty - 交互式 Web 体验

TimberKitty 展现了我作为前端工程师富有玩心与创意的一面。这个项目是一个高度交互、动画化的 Web 体验，运用现代 CSS Grid、flexbox 与进阶逻辑，在 DOM 中打造出一个游戏化的界面。 它高度聚焦于微交互——按钮如何反应、元素如何进入视图、以及用户在导航应用时的感受。 TimberKitty 展示了我将天马行空的设计概念精准落地为成品的能力，通过自定义 hooks 与 GSAP 确保跨浏览器兼容性与流畅无瑕的动画。 它证明了 Web 应用既能技术扎实，又能在使用中充满乐趣。

Young Multi 概念 - 3D 合作项目

Young Multi 项目是一个前沿的 Web 开发计划，大量运用了 WebGL 与 Three.js 能力。 作为推广/编辑类概念而设计，这个站点使用基于滚动的叙事，映射到 3D 环境中。 当用户滚动时，摄像机穿行于自定义的 3D 场景中，动态触发 HTML 覆盖层与 React 组件。 这个项目需要高级的优化技术，包括 GLTF 模型压缩、纹理图集以及自定义着色器材质，以确保即使在中端移动设备上体验依然流畅。 它是现代 Web 在视觉上所能达到的一个完美范例。
